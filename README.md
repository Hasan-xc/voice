# مولد الصوت

مولّد صوت عربي يعمل بالكامل في المتصفح، ويدعم ثلاثة مزوّدين:

- **OpenRouter** (`/api/v1/audio/speech`) — Fish Audio وGemini TTS.
- **kie.ai** — مهام غير متزامنة مع استطلاع (polling).
- **Google AI Studio** — حسابات متعددة وحصة مجانية.

لا يوجد خادم وسيط: كل الطلبات تذهب من المتصفح مباشرة إلى المزوّد.

## التشغيل محلياً

```bash
cd repos/voice
python3 -m http.server 8080   # أو أي خادم ملفات ثابت
```

افتح `http://localhost:8080`. لا تفتح `index.html` عبر `file://` لأن
IndexedDB وCSP قد لا يعملان كما ينبغي.

## الاختبارات

```bash
node tests/ai.test.js
node tests/util.test.js
```

`tests/util.test.js` يغطي: تقسيم الجمل بدون regex lookbehind، فك ترميز
Windows-1256/UTF-8/UTF-16، قراءة رؤوس WAV، إعادة أخذ العينات ودمج WAV
بمعدلات/قنوات مختلفة، تقدير التكلفة، كتالوج أصوات Gemini، واستخراج اسم
الملف من أول كلمات القصة.

## واجهة المقاطع

- **اسم الملف المدمج تلقائي**: يُشتق من أول كلمات القصة (مثلاً
  `### سر البيت القديم 🏚️` ← `سر البيت القديم`) عند رفع ملف أو لصق نص أو
  تقسيمه، ويُستخدم أيضاً لاسم ملف ZIP والملف المدمج. كتابة اسم يدوياً
  تحتفظ به ولا تُستبدل عند إعادة التقسيم.
- **أزرار عائمة داخل صندوق النص**: زر توليد أيقوني فقط، وعند التشغيل تظهر
  دائرة تدور مكانه وزر إلغاء صغير (✕). لا يوجد نص «جارٍ التوليد».
- **قائمة صوت لكل مقطع**: منسدلة بأسماء الأصوات أعلى كل بطاقة، وقيمتها
  الافتراضية «الصوت الأساسي». اختيار اسم يمرَّر مع طلب المزوّد (OpenRouter
  أو kie أو Google) فيولّد صوتاً مختلفاً لهذا المقطع فقط.
- **الصوت أسفل النص مباشرة**، وبجانبه زر تنزيل أيقوني بدل كلمة «تحميل».
- معلومات الأحرف/الكلمات صغيرة في أعلى البطاقة، وحساب/موديل المزوّد لم
  يعد مكرراً داخل البطاقة (يظهر في إعدادات المزوّد).

## الأمان وحدوده

- **المفاتيح تُحفظ في `localStorage` كنص عادي** عند تفعيل «تذكّر». أي ثغرة
  XSS أو إضافة متصفح تستطيع قراءتها. على جهاز مشترك أبقِ «تذكّر» مغلقاً.
- عند إلغاء «تذكّر» يُحذف المفتاح المحفوظ فوراً، ويبقى في الذاكرة لهذه الجلسة فقط.
- زر **🗑 مسح المفاتيح المحفوظة** يحذف مفاتيح OpenRouter وkie وكل حسابات Google
  من هذا المتصفح.
- المفاتيح تُرسل فقط إلى مزوّدها الأصلي، ولا تمر عبر أي سيرفر تابع للموقع.
- الصفحة تستخدم CSP: `script-src 'self'` (لا سكربتات خارجية)، ولا يُسمح
  بتنفيذ `eval`. مكتبة DOCX (`vendor/mammoth.browser.min.js`) مستضافة محلياً
  بدل CDN.
- لا تضع الموقع داخل iframe لموقع آخر، ولا تشارك شاشة تحتوي حقل المفتاح مفتوحاً.
- إذا تسرّب مفتاح، أبطله من لوحة المزوّد فوراً؛ حذفه من المتصفح لا يبطله.

## حدود معروفة

- **مساحة المتصفح**: حفظ الأعمال والمسودة يستخدم IndexedDB. الصوت يستهلك
  مساحة كبيرة؛ عند الامتلاء تُحفظ المسودة بدون صوت ويظهر تنبيه.
- **حصة Google المجانية**: محدودة بالدقيقة/اليوم لكل حساب. عند استنفادها
  يُعلَّم المقطع المعلق فقط وتستمر بقية المقاطع، ويمكن متابعة «توليد الكل» لاحقاً.
- **kie.ai**: قد تستغرق النصوص الطويلة أكثر من 8 دقائق؛ الحد الأقصى للاستطلاع
  20 دقيقة ثم يظهر خطأ قابل لإعادة المحاولة.
- **CORS/الشبكة**: بعض الشبكات تحجب `openrouter.ai` أو `api.kie.ai` أو
  `generativelanguage.googleapis.com`؛ يظهر خطأ اتصال عربي واضح.
- **iOS Safari**: حقول الإدخال 16px على الشاشات الصغيرة لمنع تكبير الصفحة.
  الصوت الناتج WAV من Gemini يُحوَّل من PCM حسب `rate/channels/bits` المرسلة.
- **الدمج**: دمج WAV يعيد أخذ العينات تلقائياً عند اختلاف المعدل/القنوات.
  دمج MP3 لا يفكّ ترميزه (لا فك ترميز MP3 داخل المتصفح بدون مكتبة إضافية).
- **M4B والفصول**: غير مدعوم حالياً.
- **الأسعار**: تقديرية من أسعار OpenRouter/Google المعلنة، وقد تتغير؛
  «مجاني» تعني حصة مجانية أو موديل `:free` وليست ضماناً دائماً.

## البنية

- `js/util.js` — دوال نقية قابلة للاختبار (تقسيم، ترميز، WAV/PCM، أسعار، أصوات).
- `js/core.js` — الحالة العامة، المفاتيح، العلامات القديمة (stale)، التكلفة.
- `js/storage.js` — IndexedDB (أعمال + بيانات وصفية + مسودة تلقائية).
- `js/voices.js` — كتالوج الأصوات وذاكرته.
- `js/google-accounts.js` — حسابات Google والحصص.
- `js/input.js` — الرفع والترميز والإحصاءات.
- `js/chunks.js` — التقسيم والعرض.
- `js/providers.js` — نداءات المزوّدين.
- `js/generate.js` — تنسيق التوليد والتوازي.
- `js/ai.js` — التقسيم الذكي والمخرج الصوتي.
- `js/merge-zip.js` — الدمج وZIP.
- `vendor/` — مكتبات محلية.
